<h3><img src="https://readme-typing-svg.demolab.com/?font=Fira+Code&weight=600&size=22&duration=1500&pause=10000&color=0078D4&repeat=false&width=500&height=34&lines=%24+kubectl+get+platform" alt="The platform underneath" /></h3>

All of it runs on a server at home that I treat as a playground, and it's rebuilt more often than I'd like to admit. Right now:

- **Kubernetes** with everything deployed by **GitOps** (Argo CD). If it isn't in Git, it doesn't exist.
- **Builds inside the cluster.** Push to main, and a minute later the new version is live.
- **Secrets** come from a key manager, never from Git.
- **Postgres** run by a Kubernetes operator.
- **Zero Trust** in front of everything: no open ports, identity first.
- **Home Assistant** keeping the rest of the house in order.

Next up: more nodes, and local AI on a GPU.
